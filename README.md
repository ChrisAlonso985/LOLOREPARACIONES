# LOLOREPARACIONES

LOLO es un profesor IA de reparación de celulares y notebooks.

## Incluye
- Avatar masculino animado.
- Chat técnico con modo local de respaldo.
- Micrófono en navegadores compatibles.
- Voz del teléfono y soporte para voz IA.
- Carga de fotos de placas.
- Arquitectura para visión IA y marcado GND/VBUS.
- Curso de pin de carga y evaluación.
- PWA instalable.

## Railway
El proyecto está preparado para desplegarse en Railway con Next.js.

La aplicación funciona en modo de demostración sin claves. Para activar chat/visión/voz de IA mediante Vercel AI Gateway, configurar `AI_GATEWAY_API_KEY` en Railway.
